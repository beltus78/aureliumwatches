# Notes for AI agents — aureliumwatches.com
- Plain Cloudflare Worker (TypeScript, server-rendered HTML, no framework). English only (en-US), no language prefix in URLs.
- Routing, forms, emails, sitemap: `src/index.ts` · pages: `src/pages.ts` · layout + product card: `src/html.ts` · policies/FAQ + mini markdown: `src/content.ts`.
- Business details and promises: `src/site.ts` (`SITE`, `PROMISES`). Values in [brackets] are placeholders and are hidden on the site until filled in. Never invent company details.
- Catalog: `src/catalog.ts` (`WATCHES`). Slugs are permanent URLs — never rename; add a redirect if one must change. Real photos go in `public/photos/<slug>-<n>.webp` and are switched on with `PHOTOS` in catalog.ts; otherwise `/img/w/<slug>.svg` illustrations are generated by `src/watch-svg.ts` (no brand logos).
- Payment details live ONLY in `src/payments.ts` (sent by email). Never put wallet addresses or bank details in page HTML.
- Payment methods must match in three places: `src/site.ts` (PAY), `public/app.js`, `migrations` CHECK.
- Scroll animations: `public/motion.js` + the motion block at the end of `public/styles.css` (data-story/data-chap/data-fly/data-split/data-stagger/data-reveal). Hero watch hands rotate with scroll (`.hero-watch .hm/.hh`).
- Run `npm run check` before committing. Bump `?v=` on styles.css/app.js in `src/html.ts` after changing them.
- Trademarks: the site is an independent dealer. Keep the "not affiliated" footer note; never use brand logos; brand/model names only to describe watches.

## SEO (automated tasks run on this repo)
- Deploys from `main` (Cloudflare Workers Builds).
- Guides: `src/guides.ts` (format notes at top). Served at `/guides/<slug>`. Append to `GUIDES` with `published: "YYYY-MM-DD"`, unique slug, title ≤ 65 chars, description 110–160 chars.
- Real internal URLs: `/`, `/watches`, `/pre-owned`, `/new`, `/brands`, `/brands/<slug>` (BRANDS in catalog.ts), `/watch/<slug>` (WATCHES), `/wholesale`, `/authenticity`, `/how-to-pay`, `/shipping`, `/returns`, `/faq`, `/about`, `/contact`, `/canada`, `/guides`, `/guides/<slug>`.
- Sitemap `/sitemap.xml` is built in `src/index.ts`; static pages use `CONTENT_UPDATED` — bump it only when those pages really change. Guides use their own dates.
- Log every SEO change in `seo/log.md`. IndexNow key: `0cad0245610858c9f875fdd82b994bdc` (file in `public/`).
- Market: US + Canada buyers (American English). Topics: authentication, model buying guides (Submariner, Datejust, Speedmaster, Aquanaut, Royal Oak…), pre-owned vs new, box & papers, paying with crypto, buying from Canada, dealer/wholesale buying.
- Never: fake reviews or testimonials, invented statistics, prices in guide text, promises beyond `PROMISES`, changing payment methods, contact or company details, prices, or URLs.
